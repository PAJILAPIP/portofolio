LAPORAN PRAKTIKUM

Minggu 10: Laravel UI, Bootstrap Authentication & Templating — Sistem Informasi Sekolah

Pendahuluan

Laravel adalah framework PHP yang menyediakan berbagai paket dan ekosistem untuk mempercepat pengembangan aplikasi web. Salah satu paket yang sangat populer adalah Laravel UI, yang memungkinkan developer men-generate scaffolding autentikasi secara otomatis — mencakup controller, model, view, dan route untuk fitur login, register, serta lupa password — tanpa perlu membuatnya dari nol.

Pada praktikum ini, mahasiswa mempelajari alur lengkap pembangunan aplikasi Sistem Informasi Sekolah (Sisfo) berbasis Laravel 9. Proses dimulai dari pembuatan project baru, konfigurasi database, instalasi dan konfigurasi authentication menggunakan Laravel UI dengan framework Bootstrap, kustomisasi tabel users melalui migration, pengisian data awal menggunakan seeder, hingga penerapan templating menggunakan template SB Admin 2. Selain itu juga diimplementasikan fitur manajemen users yang mencakup operasi CRUD (Create, Read, Update, Delete) secara penuh.

Lihat di GitHub

Tujuan

  • Membuat project Laravel baru menggunakan Composer atau Laravel Installer.
  • Mengkonfigurasi koneksi database pada file .env.
  • Menginstal dan mengkonfigurasi package Laravel UI untuk scaffolding authentication.
  • Men-generate fitur authentication lengkap (login, register, forgot password) menggunakan Bootstrap.
  • Mengkustomisasi tabel users dengan menambahkan kolom baru melalui migration.
  • Membuat seeder untuk mengisi data user admin awal ke database.
  • Menerapkan templating menggunakan template SB Admin 2 pada tampilan aplikasi.
  • Membuat layout global (main.blade.php) dengan komponen sidebar dan topbar menggunakan @include.
  • Mengimplementasikan fitur Manajemen Users dengan operasi CRUD (Create, Read, Update, Delete) lengkap.
  • Memahami cara kerja Resource Controller dan Resource Route dalam Laravel.

Alat dan Bahan

  • Laptop / Komputer
  • XAMPP (PHP & MySQL)
  • Visual Studio Code
  • Composer (Dependency Manager)
  • Node.js & NPM
  • Koneksi Internet

Langkah Praktikum

1. Membuat Project Laravel

Terdapat dua cara untuk membuat project Laravel baru. Cara pertama menggunakan Global Installer Laravel. Pertama, install installer Laravel secara global dengan perintah:

composer global require "laravel/installer"

Setelah installer terpasang, buat project baru dengan perintah:

laravel new laravel-sisfo

Cara kedua langsung menggunakan Composer tanpa perlu install installer global terlebih dahulu:

composer create-project laravel/laravel=^9.0 laravel-sisfo --prefer-dist

Setelah project berhasil dibuat, masuk ke folder project dan jalankan server development Laravel dengan perintah:

php artisan serve

Jika berhasil, aplikasi Laravel dapat diakses di browser pada alamat http://127.0.0.1:8000 dan akan menampilkan halaman utama Laravel default.

2. Konfigurasi Database

Sebelum memulai pengembangan, koneksi database perlu dikonfigurasi di file .env yang terletak di root project Laravel. File ini menyimpan variabel lingkungan aplikasi termasuk kredensial database.

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=laravel_sisfo
DB_USERNAME=root
DB_PASSWORD=

Konfigurasi ini memberitahu Laravel agar terhubung ke database MySQL bernama laravel_sisfo yang berjalan di localhost melalui port 3306 dengan username root dan tanpa password (sesuai konfigurasi XAMPP default).

3. User Authentication

Laravel menyediakan scaffolding authentication yang dapat di-generate secara otomatis menggunakan package Laravel UI.

Install package Laravel/UI

Jalankan perintah berikut untuk menginstal package Laravel UI ke dalam project:

composer require laravel/ui

Package ini menambahkan kemampuan untuk men-generate tampilan dan controller authentication secara otomatis menggunakan berbagai frontend framework.

Generate Authentication Scaffolding

Setelah package terinstal, jalankan perintah berikut untuk men-generate seluruh scaffolding authentication sekaligus menggunakan Bootstrap sebagai framework CSS-nya:

php artisan ui bootstrap --auth

Perintah ini secara otomatis men-generate controller authentication (LoginController, RegisterController, ForgotPasswordController, dll.), view untuk halaman login, register, dan forgot password, serta layout app.blade.php.

Install dan Compile Asset

Jalankan perintah berikut untuk menginstal seluruh dependensi JavaScript dan mengkompilasi file aset (CSS dan JS) dari scaffolding yang baru saja di-generate:

npm install && npm run dev

Migration Authentication

Jalankan migration untuk membuat tabel-tabel yang dibutuhkan oleh sistem authentication, termasuk tabel users, password_resets, dan personal_access_tokens:

php artisan migrate

Jika database laravel_sisfo belum ada, Laravel akan menampilkan konfirmasi untuk membuatkannya secara otomatis. Setelah migration berhasil, aplikasi sudah memiliki halaman login di /login dan halaman register di /register.

4. Custom Table Users

Tabel users yang di-generate Laravel secara default hanya memiliki kolom id, name, email, password, dan beberapa kolom bawaan lainnya. Untuk kebutuhan aplikasi Sisfo, perlu ditambahkan tiga kolom baru: username, level, dan status.

Buat file migration baru khusus untuk memodifikasi tabel users yang sudah ada:

php artisan make:migration costum_table_users

Perintah ini membuat file migration baru di folder database/migrations. Berbeda dengan migration create, migration ini menggunakan Schema::table() (bukan Schema::create()) karena hanya menambahkan kolom pada tabel yang sudah ada. Kolom yang ditambahkan adalah:

  • username — bertipe string dan bersifat unik, digunakan sebagai identitas login alternatif.
  • level — bertipe string, menyimpan peran pengguna dalam sistem (disimpan dalam format JSON seperti ["ADMIN"]).
  • status — bertipe enum dengan dua nilai yang diizinkan: ACTIVE atau INACTIVE, untuk mengelola keaktifan akun.

Setelah mendefinisikan kolom baru di method up() dan perintah rollback di method down(), jalankan migration:

php artisan migrate

Jika berhasil, struktur tabel users akan bertambah tiga kolom baru sesuai yang didefinisikan.

5. Seeding User Admin

Seeder digunakan untuk mengisi data awal ke database secara programatik. Pada tahap ini dibuat seeder khusus untuk mengisi akun administrator pertama:

php artisan make:seeder AdminSeeder

File AdminSeeder.php dibuat di folder database/seeders. Di dalam method run(), dibuat instance model User dan setiap propertinya diisi secara langsung. Password dienkripsi menggunakan \Hash::make() sehingga tidak tersimpan dalam bentuk plain text di database. Kolom level disimpan dalam format JSON menggunakan json_encode(["ADMIN"]) karena satu user dapat memiliki lebih dari satu level.

Untuk menjalankan seeder secara spesifik tanpa harus menjalankan semua seeder, gunakan flag --class:

php artisan db:seed --class=AdminSeeder

Jika berhasil, terminal akan menampilkan pesan konfirmasi dan akun admin dapat digunakan untuk login ke aplikasi.

6. Templating dengan SB Admin 2

Setelah authentication berfungsi, tampilan aplikasi dikustomisasi menggunakan template SB Admin 2 yang berbasis Bootstrap. Template ini diunduh dari https://startbootstrap.com/theme/sb-admin-2, diekstrak, lalu seluruh isinya di-copy ke folder public/sbadmin di dalam project Laravel agar dapat diakses melalui helper asset().

Halaman Login (app.blade.php)

File resources/views/layouts/app.blade.php yang sebelumnya menjadi layout default authentication diganti total dengan template login dari SB Admin 2. File ini memuat aset CSS dan JS SB Admin 2 menggunakan helper {{ asset('sbadmin/...') }} sehingga tampilannya berubah dari login Bootstrap default menjadi halaman login bergaya admin panel dengan latar warna biru gradasi.

Layout Global (main.blade.php)

Karena app.blade.php sudah dialokasikan untuk halaman login, dibuat layout baru bernama main.blade.php di folder resources/views/layouts. Layout ini berfungsi sebagai template induk untuk semua halaman dalam aplikasi setelah login. Dua komponen penting dipanggil menggunakan direktif @include:

@include("layouts.sidebar")   (memuat komponen sidebar kiri)
@include("layouts.topbar")   (memuat komponen navbar atas)

Layout ini juga menyediakan dua blok @yield untuk diisi oleh view yang menggunakannya: @yield('judul') untuk judul halaman dan @yield('konten') untuk konten utama halaman tersebut.

Sidebar (sidebar.blade.php)

Dibuat file resources/views/layouts/sidebar.blade.php yang berisi kode HTML untuk panel navigasi kiri bergaya SB Admin 2. Sidebar ini menampilkan brand aplikasi (Sisfo) dan daftar menu navigasi.

Topbar (topbar.blade.php)

Dibuat file resources/views/layouts/topbar.blade.php yang berisi navbar bagian atas. Topbar menampilkan nama pengguna yang sedang login menggunakan {{ Auth::user()->name }} dan menyediakan dropdown menu dengan opsi Profile, Settings, dan Logout. Tombol Logout memanggil route logout dengan method POST agar aman dari serangan CSRF.

Cara Menggunakan Layout Main

Setiap view yang ingin menggunakan layout main cukup menambahkan direktif berikut di awal file:

@extends('layouts.main')
@section("judul") Nama Halaman @endsection
@section('konten') ... konten halaman ... @endsection

Dengan pola ini, setiap halaman hanya perlu mendefinisikan judul dan kontennya — sidebar, topbar, dan footer sudah otomatis diwarisi dari layout main.

7. Manajemen Users (CRUD)

Fitur manajemen users dibuat menggunakan Resource Controller yang secara otomatis menyediakan tujuh method CRUD sekaligus:

php artisan make:controller UserController --resource

Route resource didaftarkan di routes/web.php sehingga semua endpoint CRUD untuk users langsung tersedia:

Route::resource('users', UserController::class);

Untuk melihat semua route yang terdaftar beserta HTTP method dan action-nya:

php artisan route:list

CREATE USER

Method create() pada UserController mengembalikan view form tambah user. Form ini memiliki field Nama, Email, Username, Password, dan Level (menggunakan Select2 untuk multiple select). Library Select2 ditambahkan ke main.blade.php via CDN agar dropdown level dapat dipilih lebih dari satu nilai sekaligus.

Method store() menangkap data dari form menggunakan $request->get('nama_input'), membuat instance model User baru, mengisi setiap propertinya, mengenkripsi password dengan \Hash::make(), menyimpan level dalam format JSON, lalu memanggil $user->save() untuk menyimpan ke database. Jika berhasil, pengguna di-redirect ke halaman index users dengan membawa pesan sukses melalui session.

READ / LIST USERS

Method index() mengambil semua data user dengan \App\Models\User::all() dan mengirimkannya ke view users.index. View ini menampilkan data dalam tabel yang dilengkapi dengan DataTables untuk fitur pencarian, pengurutan, dan paginasi secara otomatis. File CSS dan JS DataTables ditambahkan ke layout main.blade.php. Tombol "Tambah User" mengarahkan pengguna ke form create menggunakan route('users.create').

UPDATE USER

Tombol Edit pada setiap baris tabel mengarahkan ke route users.edit yang membawa ID user. Method edit($id) mengambil data user berdasarkan ID menggunakan \App\Models\User::findOrFail($id) — jika ID tidak ditemukan akan otomatis mengembalikan response 404. Data user dikirim ke view user.edit untuk ditampilkan pada form edit.

Form edit menggunakan method POST dengan tambahan input hidden _method = PUT karena HTML form tidak mendukung method PUT secara langsung. Nilai setiap field diisi dari data user yang ada. Untuk kolom level, kondisi in_array() digunakan untuk menandai opsi yang sudah terpilih sebelumnya. Method update() menyimpan perubahan dengan cara yang sama seperti store().

DELETE USER

Tombol Hapus pada setiap baris tabel menggunakan form HTML dengan method POST dan input hidden _method = DELETE. Atribut onsubmit="return confirm('...')" menampilkan dialog konfirmasi sebelum data benar-benar dihapus. Method destroy($id) mencari user berdasarkan ID, memanggil $user->delete() untuk menghapus dari database, lalu me-redirect kembali ke halaman index dengan pesan sukses.

Menambahkan Menu Users di Sidebar

Agar menu Users dapat diakses dari sidebar, tambahkan item navigasi baru ke file resources/views/layouts/sidebar.blade.php menggunakan helper route route('users.index') beserta ikon Font Awesome yang sesuai.

Kesimpulan

Berdasarkan praktikum yang telah dilakukan, dapat disimpulkan bahwa Laravel menyediakan ekosistem yang lengkap untuk membangun aplikasi web secara cepat dan terstruktur. Package Laravel UI memungkinkan developer men-generate seluruh scaffolding authentication — mencakup controller, view, dan route — hanya dengan satu perintah, sehingga menghemat waktu pengembangan secara signifikan. Sistem migration Laravel juga terbukti fleksibel; tidak hanya untuk membuat tabel baru, tetapi juga untuk memodifikasi tabel yang sudah ada seperti yang dilakukan pada kustomisasi tabel users. Pada sisi tampilan, penerapan templating menggunakan SB Admin 2 menunjukkan bagaimana Blade Layout dengan direktif @extends, @yield, @section, dan @include dapat memisahkan komponen tampilan secara rapi sehingga mudah dipelihara dan dikembangkan lebih lanjut. Implementasi Resource Controller juga mempercepat pembuatan fitur CRUD karena tujuh method standar sudah tersedia secara otomatis dan dapat langsung diisi dengan logika bisnis yang dibutuhkan.
